# Stock_Market_Sim

## Project Goal: 
This project is a Java-based stock market simulator designed to help beginner investors understand how their investment decisions perform under different market conditions. Users can practice trading with historical stock data without risking real money or knowing future stock prices.

## MVP Features:
Start with $10,000 in virtual money.
Load historical stock prices from CSV files.
Buy and sell stocks using virtual money.
Advance through historical trading days without revealing future prices.
Track cash balance, shares owned, and total portfolio returns.

## Future Plans:
Add graphs to visualize stock price movements.
Allow users to save and resume simulations.
Support more stocks and compare investment performance against the S&P 500.

## Tech Stack:
Language: Java
Libraries: Scanner, BufferedReader, ArrayList, LocalDate
Data Storage: CSV files containing historical stock prices
Development Tools: Visual Studio Code and GitHub
Interface: Command-line menu

## Development Plan:
The project will be developed in stages, beginning with CSV file loading and basic user interaction. Then I'll implement buying and selling, trading-day progression, and portfolio tracking. Finally, I'll test the program and improve its functionality and documentation.
